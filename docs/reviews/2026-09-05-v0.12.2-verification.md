# IntentTrace 0.12.2 문구 수정 검증

확인일: 2026-09-05

[문구 검토](2026-09-05-wording-review.md)의 40개 수정안을 모두 반영했다. 화면·Markdown 출력·MCP 설명·Zed 오류·사용 안내에서 반복되는 표현도 맞췄다.

## 적용 내용

| 범위 | 반영 내용 |
|---|---|
| 사실과 다른 해석 방지 | 결과 미등록을 미실행으로 단정하지 않는다. 다른 스냅샷·PR 커밋 불일치·서버 5xx를 확인한 사실대로 표시한다. |
| 화면 제목과 안내 | ‘구현 결정과 이유’, ‘관련 코드’, ‘커밋 해시’, ‘원본과 새 기록’으로 표현을 맞췄다. 조회 중단·재시도 안내를 줄였다. |
| Zed·로그인 | 세션 토큰 입력 위치, 재로그인, 변경 요청 재시도 전 상태 확인, 연결 도구 재설치를 구체적으로 안내한다. |
| 문서 | README·HANDOFF·관련 PRD/ADR·사용 스킬과 Zed 설치 안내를 수정했다. 이전 검증 기록의 사실과 수치는 유지했다. |
| 모바일 표시 | 제목과 안내가 단어 단위로 줄바꿈되도록 조정했다. 긴 문자열의 줄바꿈은 허용한다. |

REST·MCP 이름, JSON 필드, enum, 오류 코드, 설정 키는 변경하지 않았다. 권한·인증·기록 상태 전이와 DB 저장 방식도 유지했다. 버전은 서버·플러그인·Zed 연결 도구에 0.12.2로 맞췄다.

## 실행한 검증

| 확인 | 결과 |
|---|---|
| 검토표와 소스 대조 | 40개 권장 문구가 각각 지정된 파일에 있음. 동적 건수와 HTML 표시는 소스 형식에 맞춰 확인. |
| `./gradlew test` | 93개 중 92개 통과, 실패 0개, PostgreSQL 전용 1개 제외. |
| `npm test --prefix clients/zed` | Node 9개·Python 3개 통과. 패키지의 빈 캐시 오프라인 설치와 로컬 MCP 연결 포함. |
| 오류 안내 | 잘못된 세션 토큰을 넣으면 환경 변수 안내를 전달하고 실제 입력값을 출력하지 않음. 인증·5xx·시간 초과 문구와 오류 코드 확인. |
| 플러그인·스킬 | `scripts/validate-plugin.sh`와 두 스킬의 `quick_validate.py` 통과. |
| 모바일 화면 | 실제 Chromium 390×900에서 로그인·조회 중단·원본 비교 확인. 제목의 단어 분리와 가로 넘침 없음. |
| Zed 설치 파일 | 0.12.2 파일 생성. 압축 파일·잠금 파일 해시, 포함된 실행 파일·사용 안내가 현재 소스와 일치. |

새 테스트 파일은 추가하지 않았다. 기존 테스트의 문구 기대값과 오류 전달 확인만 보완했다. 모바일 화면은 서버 통합 테스트가 생성한 HTML을 사용했으며, 로그인·화면 이동·데이터 처리는 서버 통합 테스트로 확인했다. 화면 이미지는 로컬 `output/playwright/v12-2-*.png`에 저장했다.

DB 변경이 없어 별도 PostgreSQL 검증은 재실행하지 않았다. 실제 Zed 앱·GitHub 사용자 승인·외부 게시는 이번 검증에 포함하지 않았다.
