# IntentTrace 0.12.3 문구 수정 검증

확인일: 2026-09-05

[추가 문구 검토](2026-09-05-wording-follow-up-review.md)의 12개 수정안을 모두 반영했다. 서버·플러그인은 0.12.3이며 Zed 연결 도구는 0.12.2를 사용한다.

## 적용 내용

- 요청 충돌 안내에 작성자·저장소·내용을 포함하고, 스냅샷 해시 불일치로 공개할 수 없음을 설명한다.
- 전체 연결 종료 안내에 본인의 모든 브라우저·Agent·API 연결을 포함한다.
- 토큰 발급 성공과 저장소 범위 확인을 별도로 설명한다. 사용 스킬에도 GitHub에서 발급받아 메모리에 보관한다는 의미를 반영했다.
- 검증 결과 제목·검색 입력·연결 진단·MCP 설명·관련 코드 입력 오류·플러그인 소개와 기본 프롬프트의 용어를 맞췄다.

오류 유형·발생 조건, 기록 상태 전이, 권한·세션 관리와 DB 저장 방식은 변경하지 않았다. REST·MCP 이름, 입력·응답 필드와 상태 코드도 유지했다.

## 실행한 검증

| 확인 | 결과 |
|---|---|
| 검토표와 소스 대조 | 12개 권장 문구가 지정된 파일에 모두 있음. |
| `./gradlew test` | 93개 중 92개 통과, 실패 0개, PostgreSQL 전용 1개 제외. |
| 요청 충돌·공개 실패 | 같은 작성자·저장소에서 내용이 다른 요청과 스냅샷 해시 불일치의 오류 안내 확인. |
| 전체 연결 종료 | 다른 브라우저와 Agent·API 연결까지 본인 연결을 종료하고, 다른 사용자의 연결은 유지함을 확인. |
| GitHub 게시 인증 점검 | 토큰 발급에 성공해도 저장소 범위·권한 검사는 별도로 실패할 수 있음과 각 단계의 안내 확인. GitHub 응답은 테스트 대역 사용. |
| 기존 Zed 연결 | 0.12.2 연결 도구와 실제 Spring 서버 0.12.3의 인증·MCP 도구 목록·진단 호출 통과. |
| 플러그인·스킬 | `scripts/validate-plugin.sh`와 변경한 `skills/intent-trace`의 `quick_validate.py` 통과. |

새 테스트 파일은 추가하지 않았다. 기존 테스트 4개에 필요한 확인만 보완했다. 실제 브라우저·Zed 앱·GitHub 사용자 승인·외부 게시는 이번 검증에 포함하지 않았다. DB 변경이 없어 별도 PostgreSQL 검증은 재실행하지 않았다.

Zed 실행 파일과 의존성은 변경하지 않았으며 기존 0.12.2 설치 파일을 사용한다. 이번에는 설치 파일 생성과 Zed Node·Python 테스트를 반복 실행하지 않았다.
