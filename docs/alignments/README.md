# Alignment HTML 보존 정책

이 디렉터리에는 초기 팀 인증·배포 결정을 검토한 다음 두 개의 Hope HTML만 유지합니다.

- `team-identity-and-repository-access.html`
- `team-deployment-and-session-boundary.html`

앞으로 제품 결정은 PRD와 ADR의 Markdown을 기준 문서로 사용합니다. 새 Hope HTML이 필요하면 GitHub Release나 별도 보관소에 첨부하고 Git 저장소에는 추가하지 않습니다.

현재 HTML에 포함된 렌더러와 글꼴의 라이선스는 저장소 루트의 `THIRD_PARTY_NOTICES.md`에서 확인할 수 있습니다.
